# SubMate 노션 교체용 상세 문서

기준일: 2026-10-19. 제공한 노션 원문과 현재 로컬 코드·설정·DDL·DTO를 대조한 페이지별 전체 교체용 본문입니다. 이전 요약본은 별도 폴더에 보존했습니다. 노션에는 직접 반영하지 않았습니다.

## 1. 사용 방법

1. 기존 노션 페이지를 복제하거나 변경 이력을 보존합니다.
2. 같은 제목의 파일을 열어 첫 제목부터 마지막 체크리스트까지 전체 복사합니다.
3. 해당 노션 페이지 본문을 교체하고 표·코드 블록·내부 링크를 확인합니다.
4. 신규 역할·모델·API 제안은 팀 합의 후 확정으로 갱신합니다.

각 문서는 독립적으로 읽을 수 있도록 현재 정책과 계획 상태를 포함합니다. 문장 수를 그대로 유지하는 대신 원문 기능·필드·절차를 보존하고 충돌하는 내용은 근거를 적어 정정했습니다.

## 3. 상세화한 내용

- API: 현재 14개 경로, DTO 전 필드·NULL·검증·응답·오류, 미구현 회원/상품·강의·학습·공지·통계 계약 제안.
- DB: 원본 회원/상품/분류/게시판 필드, 실제 거래 3개 테이블 필드·제약·인덱스, 신규 학습 4개 테이블 전체 설계.
- 실행: 설치·clone·브랜치·IDE·DB/DDL·환경변수·데모/실제 모드·로그·오류·Git·체크리스트.
- 구조: 실제 클래스·폴더·페이지와 신규 구조를 분리, API/세션/스타일 연결 상세.
- 협업: R&R·PR·충돌·정리·주석·보안·완료 기준.
- 프론트: 실제 토큰·폼/버튼/카드·반응형·접근성·학습 화면 기준.

## 4. 공통 정책

서비스는 학습·강의 콘텐츠 구독입니다. Product는 이용권, Course는 강의, Lesson은 차시입니다. 현재 월간/연간은 최초 1회 가상 결제이며 정기 청구가 아닙니다.

현재 코드의 해지 후 종료일까지 이용·잔여 일수 환불·승인 즉시 종료 정책을 문서 전체에 적용했습니다. POST /api/subscriptions에서 구독/결제를 함께 생성하고 성공 DTO를 직접 반환합니다.

## 5. 팀 합의 전 제안

Product-Course N:M, 기존 이용권 강의 구성 변경 영향, 신규 강의/학습 역할, 콘텐츠 형식·공개 상태·완료 기준·미리보기, 일반 게시판 범위, 미구현 API/삭제/통계 정책은 제안입니다. 상세하게 적었다고 합의·구현·검증이 완료된 것은 아닙니다.

## 6. 검증 범위

Controller·DTO·Service·DDL·실행 설정과 문서를 대조하고 정적 검사 결과를 12번 문서에 기록했습니다. 백엔드 27건은 기존 2026-09-28 기록이며 이번에는 테스트를 재실행하지 않았습니다.

실제 JWT/MySQL 통합·신규 강의/진도 구현·브라우저 E2E·팀원 별도 브랜치 최신 상태는 이번 문서 작업에서 완료로 간주하지 않습니다. 정적 대조는 실제 기능 실행을 대신하지 않습니다.
