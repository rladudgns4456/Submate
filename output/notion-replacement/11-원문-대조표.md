# SubMate 원문·교체본 대조표

원문은 첨부 9개 파일(동일 Git 전략 2개 포함)과 본문 R&R입니다. 프론트엔드 가이드는 새 작성 대상입니다. 원문 주제가 새 문서의 어디에 반영되었는지와 의도적으로 정정한 내용을 정리했습니다. 문장 수를 그대로 유지하는 비교가 아니라 기능·규칙·필드·절차의 보존 비교입니다.

기본(1), 네이밍(2·11), 계층(3·12), Frontend(4·13), API/HTTP(5·14), Git/commit(9와 Git 문서), 주석(14), 상태(6·15), DB/예외/보안(8·14·15), 리뷰(9·17), 팀 경계(16), 완료(10·18)를 보존했습니다. ‘테스트 코드 제거’는 ‘임시 코드 정리·실제 테스트 유지’로 정정했고 users/user_id를 members/member_id로 통일했습니다.

## 8. 개발 요청 프롬프트

원문의 프로젝트·기술·담당·사용자·결제·기간·상태·환불·관리자·게시판/통계·데이터·검수·결과 형식을 1~15절에 반영했습니다. 현재 코드 정책과 충돌하는 내용을 정정하고 11~15절에 상세 요구·검수·결과 형식을 복원했습니다. 신규 역할·모델·계약은 제안으로 표시했습니다.

## 9. 본문 R&R — 원문 8절

## 10. 프론트엔드 — 신규

색상·폰트·간격·모서리·버튼·입력·카드·상태·학습 화면·반응형·접근성·검증·토큰을 1~16절로 작성했습니다. 실제 공통 토큰과 아직 없는 학습 화면 목표를 구분했습니다.

## 11. 의도적으로 정정·확장 분리한 항목

| 원문 | 교체 기준 |
|---|---|
| 즉시 해지/잔여 이용 제외 | 현재 CANCELLED 잔여 이용 |
| 임의 이용 일수+시각 | 현재 월/연·DATE·한국 자정 |
| 24시간 전액/실패 재처리 | 현재 일할·승인/반려·요청 1회 |
| 부분 환불 제외 | 임의 금액/학습량 차감 제외, 일할 유지 |
| PAID·별도 결제 생성 | COMPLETED·checkout 통합 |
| 성공 래퍼 | DTO 직접 응답·이관 없는 래퍼 금지 |
| 일반 글쓰기 현재 기능 | 후속 확장 보존·공지 기본안 |
| 모든 폴더가 존재하는 구조 | 실제와 추가 계획 분리 |
| setx 후 비밀번호 출력 | 범위 설명·존재만 확인 |
| 초기 연결 성공 문구 | 로그인·API 저장/재조회 |
| 테스트 코드 제거 | 실제 회귀 테스트 유지 |

이는 현재 코드와의 충돌을 제거한 변경입니다. 다른 정책을 선택하면 코드·DDL·API·테스트·화면·문서를 함께 이관합니다.
