## 전체 문서에 적용한 변경

- 서비스 방향: 학습·공부·강의 콘텐츠 구독 서비스.
- Product는 이용권·가격·기간, Course/Lesson은 학습 콘텐츠로 구분.
- 강의 탐색·상세·수강·진도 관리는 신규 개발 범위. 문서 작성만으로 구현 완료 처리하지 않음.
- 월/연 상품은 최초 한 번 가상 결제로 기간 이용. 자동 청구 없음.
- 해지 후 종료일까지 이용 가능. ACTIVE/CANCELLED 모두 종료일에 EXPIRED.
- 환불은 요청일 기준 잔여 일수로 계산하며 승인 시 즉시 이용 종료. 24시간 전액 환불 정책 삭제.
- 구독·결제 생성은 POST /api/subscriptions 한 번으로 처리. 별도 POST /api/payments 흐름 삭제.
- 원결제당 환불 요청 1회이며 반려 후 재요청 불가. 실패 환불 재처리는 현재 기능에 없음.
- 기존 API는 DTO 직접 응답. 미구현 공통 래퍼를 현재 규칙으로 적지 않음.
- 현재 구현과 후속 계획, 신규 역할 분담 제안을 구분.

## 팀 합의가 필요한 제안

- Product와 Course를 N:M으로 연결해 하나의 이용권에 여러 강의를 포함하는 모델.
- 김현빈: 강의 목록·상세·차시 관리 / 김영훈: 수강 권한·진도·이어 학습하기.
- 첫 콘텐츠는 텍스트·학습 자료 중심, 선택적으로 사용 권한이 있는 영상 링크 제공. 업로드·스트리밍 서버는 제외하는 안.
- 게시판은 공지사항을 기본으로 하고 질문·답변·댓글은 후속 확장.
- 상품 구성 변경이 기존 구독의 강의 접근 범위에 미치는 영향, 강의 완료 기준, 공개 미리보기 범위.

이 제안은 아직 팀원 합의나 기능 구현이 완료되었다는 의미가 아닙니다.

- 백엔드 27건 통과는 기존 2026-09-28 문서 기록이며 이번 문서 작업에서 재실행하지 않았습니다.

- 원격의 최신 진행 상황이나 팀원의 별도 브랜치 구현 상태는 이번 수정본에서 확인한 것으로 간주하지 않습니다.
